GEORGE

Charles Hamblin's General Order Generator for the English Electric DEUCE, 1957-58: programs in "reverse Polish" notation for a pseudo-machine with a running accumulator of twelve cells, used last in, first out. This is the same Rust program as the command line, compiled to WebAssembly and running in your browser. Hover over a symbol to see what it does, its code in the coding table and the words of the manual. Tick Trace to step through the accumulator a symbol at a time. Source, manual and decisions.
